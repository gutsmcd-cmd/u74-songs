# 歌で覚える / Study Songs — Universe 74

Turn a topic or notes (or a summary from まとめ屋) into catchy memory lyrics — rap, pop, nursery rhyme or chant — then play them over a simple generated beat and melody (WebAudio) with karaoke-style lyrics. Optional robot-voice chant (speechSynthesis), lyrics/WAV export, and a "copy prompt & open Suno" button.

Honest note: it doesn't generate real sung vocals.

The AI runs in your browser (transformers.js, Qwen2.5-0.5B/1.5B-Instruct, cached after first download). Optional Gemini key, off by default. Free, no ads, no login. Part of the [Universe 74 App House](https://gutsmcd-cmd.github.io/universe-74/).

Test without downloading a model: add `?mock` to the URL.
